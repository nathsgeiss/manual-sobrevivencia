Glossário do primeiro mês

Dez palavras que aparecem o tempo todo e que quase ninguém para para definir. Se alguma delas ainda soa vaga, é normal — usar vem antes de explicar.

Tag

A marcação escrita entre < e >, como <p>.

Elemento

A tag de abertura, o conteúdo dentro dela e a tag de fechamento, juntos.

Atributo

Informação extra escrita dentro da tag de abertura, como href.

Seletor

A parte da regra de CSS que decide quais elementos serão afetados.

Propriedade

O que você quer mudar naquele elemento: cor, tamanho, espaçamento.

Herança

Quando um elemento recebe do pai um valor que ninguém escreveu para ele.

Contêiner

Um elemento que existe para envolver outros e servir de apoio ao layout.

Bloco

Elemento que ocupa a linha inteira e empurra o resto para baixo.

Inline

Elemento que ocupa só o espaço do próprio conteúdo, dentro da linha.

Commit

Um ponto salvo no histórico do projeto, com uma mensagem explicando o quê.

Como usar esta página

Quando travar numa explicação, procure aqui primeiro. Se a definição não resolver, o problema provavelmente não é a palavra — é o conceito, e aí vale perguntar.
