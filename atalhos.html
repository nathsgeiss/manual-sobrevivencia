Atalhos que valem decorar

Ninguém decora atalho lendo lista. Escolha dois desta página e force o uso por uma semana, mesmo quando for mais lento fazer pelo mouse. Depois volte e pegue mais dois.

No editor

  • Ctrl + S — salvar
  • Ctrl + / — comentar a linha
  • Ctrl + D — selecionar a próxima ocorrência
  • Alt + ↑ ↓ — mover a linha
  • Ctrl + P — abrir arquivo pelo nome

No navegador

  • F12 — abrir as ferramentas
  • Ctrl + Shift + C — inspecionar elemento
  • Ctrl + R — recarregar
  • Ctrl + Shift + R — recarregar ignorando o cache
  • Ctrl + F — procurar na página

No terminal, com Git

  • git status — o que mudou
  • git add . — separar tudo para o commit
  • git commit -m — registrar
  • git push — enviar para o GitHub
  • git log --oneline — ver o histórico

Como decorar sem tentar decorar

  1. Escolha dois atalhos, não a lista inteira.
  2. Use os dois mesmo quando for mais lento — e vai ser, nos primeiros dias.
  3. Quando a mão for sozinha, escolha os próximos dois.

Ctrl + Shift + R é o que mais economiza tempo em aula: quando o CSS parece não ter mudado, quase sempre é o navegador reaproveitando a versão antiga do arquivo.
